# Final Pool

This branch consolidates all IMPLEMENTED tasks from the BenchTasksCollv3 development branches.

An "implemented" task satisfies the requirements in `tasks/examples`:
- `docs/agent_system_prompt.md` exists, is non-empty, and is all English (no Chinese)
- `docs/task.md` exists, is non-empty, and is all English (no Chinese)
- `evaluation/main.py` exists

Each task is placed under `tasks/finalpool/<task-name>/` following the project's task structure.
